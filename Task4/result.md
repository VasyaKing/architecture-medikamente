## Ключевые компоненты, затрагиваемые миграцией

| Направление        | Компоненты                                                                                |
|--------------------|-------------------------------------------------------------------------------------------|
| **Инфраструктура** | Серверы, сеть, VPN, storage, Kubernetes, облако                                           |
| **Данные**         | миграция файлов → структурированное хранилище; перенос Excel → БД; миграция 1С-интеграций |
| **Коммуникации**   | API Gateway, сервисы, шина событий, интеграция с лабораторией                             |
| **Бизнес-логика**  | запись к врачу, обработка анализов, биллинг, медкарты                                     |
| **Безопасность**   | IAM, PDP, KMS, DLP, аудит                                                                 |
| **Персонал**       | IT-команда, медперсонал, кассиры, бухгалтерия, обучение                                   |
