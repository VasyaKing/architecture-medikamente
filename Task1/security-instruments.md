## Инструменты защиты данных

1) Шифрование хранилищ

| Хранилище                             | Механизм                                           |
|---------------------------------------|----------------------------------------------------|
| Postgres                              | pgcrypto, Vault Encryption Plugin                  |
| S3                                    | S3 Server-Side Encryption                          |
| Файловый сервер                       | BitLocker                                          |
| ClickHouse                            | Дисковое шифрование + шифрование данных в столбцах |
| 1С (после миграции в серверный режим) | аппаратное шифрование дисков + шифрование БД       |

2) Защита данных при передачи

* TLS 1.2
* HTTPS
* mTLS

- OpenVPN / Nginx

3) Защита данных в приложениях

| Роль        | Доступ                                             |
|-------------|----------------------------------------------------|
| Ресепшен    | Только PII пациента (ФИО, контакты), без диагнозов |
| Врач        | Полный доступ к медданным своего пациента          |
| Бухгалтер   | Только финансы, без медкарт и ПДн                  |
| Склад       | Только ТМЦ                                         |
| Лаборатория | Только биоматериал/ID заказа, без ФИО              |

- Keycloak / ABAC

4) Механизмы маскировки

| Данные  | Маскировка          |
|---------|---------------------|
| Паспорт | `•••• ••••••`       |
| Телефон | `+7••• •• ••`       |
| Адрес   | только город        |
| Email   | `kk••••@yandex.com` |

5) Тегирование данных

| Тег                 | Действие                                |
|---------------------|-----------------------------------------|
| `patient.pii`       | шифровать, маскировать                  |
| `patient.medical`   | шифровать, не логировать                |
| `finance.payment`   | хранить зашифрованным                   |
| `pii-remove-for-bi` | удалять/обезличивать при загрузке в DWH |

5) Защита файлов
- Нельзя хранить медкарты на общей сетевой папке.

6) Аудит и мониторинг

* ELK 
* VictoriaMetrics / Grafana

7) Сегментация сети и Zero Trust

* Контур врачей
* Контур бухгалтерии
* Контур склада
* Контур лаборатории
* DMZ для внешних API

8) IAM

* 2FA
* политики сложности паролей
* политики ротации паролей
* аппаратные ключи
